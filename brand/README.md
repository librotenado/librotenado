# brand – copies

Copies of what librotenado/librotenado shows of its brand, from
[librotenado/brand](https://github.com/librotenado/brand), the brand's one source: the lockups for the README,
`web/favicon.svg` and `web/icon-192.png` for the documentation, and the fonts (Atkinson Hyperlegible Next and Mono)
the documentation bundles. Change the brand there and copy it here – never edit these files in place.
